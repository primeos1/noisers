## Design Context

### Users
Football/5-a-side players and team managers/coaches. **Everyone is on mobile** — players check squad cards and stats from their phones at the pitch or after games; managers use the admin panel on phones to manage rosters, track matches, and review reports. Urgency matters: decisions are made quickly pitch-side, so the UI must be scannable at a glance.

### Brand Personality
- **Competitive** — serious athletic platform, not a hobby app
- **Direct** — heavy type, numbers that pop, no decoration for decoration's sake
- **Grounded** — earned credibility, like a coaching board or broadcast graphic

### Aesthetic Direction
- **Theme**: Dark. Dark pitch-grey base (`#141418`), burgundy (`#7c1d35`) as primary/active, forest green (`#2d6a4f`) as success/positive.
- **Font**: Jost (user-specified). Weight 800–900 for display numerics, 600–700 for labels, 400–500 for body.
- **Anti-references**: No glassmorphism, no neon/cyberpunk palette, no Bootstrap-style admin panels with sidebars full of icon+text rows, no gradient text, no left-border accent stripes.
- **Reference feel**: Premium European sports analytics — think broadcast graphics, team sheet printouts, match programme layouts.

### Design Principles
1. **Data first** — numbers are the hero. Large, heavy weights, no visual clutter competing with them.
2. **Mobile-first layout** — bottom tab nav on all pages; sidebar only appears at desktop breakpoint (≥1024px).
3. **No unnecessary icons** — SVG icons only in navigation tabs and action buttons where they replace text. Never decorative icons next to every heading.
4. **Sharp, not flashy** — use `border-radius: 6–10px`, solid borders, no glow effects. Burgundy is the only colour that "pops".
5. **Consistent component vocabulary** — `card`, `stat-box`, `badge`, `btn`, `data-table` from `design-system.css` used throughout all pages.

### Technical Stack
- PHP + XAMPP (no build tools)
- Tailwind CDN Play (`https://cdn.tailwindcss.com`) with inline config in every page head (via `includes/head.php`)
- Jost from Google Fonts (loaded in `includes/head.php`)
- Custom design system: `assets/css/design-system.css`
- No JavaScript frameworks — vanilla JS + inline Alpine-style patterns where needed
- No FontAwesome — SVG icons inline only

### File Architecture
| File | Role |
|---|---|
| `includes/head.php` | Shared `<head>` content: meta, Jost, Tailwind CDN + config, design-system link |
| `assets/css/design-system.css` | Full CSS design system: tokens, layout, components |
| `includes/navbar.php` | Admin top-bar + mobile bottom tabs (for non-dashboard pages) |
| `includes/player_nav.php` | Player top-bar + bottom tabs |
| `admin/dashboard.php` | Inline sidebar (desktop) + bottom tabs (mobile) |
